## Струтура проекта
- `database.py` — класс BookDB для работы с базой данных
- `main.py` — консольный интерфейс
- `tests/test_database.py` — модульные тесты

## Функциональность
- Добавление, просмотр, поиск, обновление, удаление книг
- Сортировка по любому полю
- Обработка ошибок ввода

## Запуск
```bash
python main.py
