# Лабораторная работа №3

## Структура
- src/db/backend/memory.py - класс Database
- src/db/tui.py - класс TUI (интерфейс)
- src/db/__main__.py - запуск
- tests/test_database.py - тесты

## Что делает программа
- Добавление, просмотр, поиск, обновление, удаление записей
- Поиск по нескольким полям сразу
- Все ошибки обрабатываются

## Запуск
python -m src.db

## Запуск тестов
python -m unittest discover tests

## База данных
Студенты: id, имя, фамилия, возраст, пол
