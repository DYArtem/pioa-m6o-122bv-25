# Прототип базы данных (in-memory)

## Структура проекта
- `database.py` — содержит функции для работы с базой данных
- `main.py` — тут консольный интерфейс для взаимодействия с пользователем

## Функциональность
- Добавление новых книг
- Просмотр всех книг
- Поиск книг по любому полю например можнр по названию
- Обновление информации о книге
- Удаление книги
- Обработка ошибок

## Запуск
```bash
python main.py


## Предметная область
Библиотека. Таблица `books` содержит поля:
- id (уникальный номер)
- title (название)
- author (автор)
- year (год издания)
- status (статус: "в наличии" / "выдана")
