# Лабораторная работа №2: in-memory база данных

## Структура проекта

Проект реализует in-memory базу данных для студентов с поддепжкой CRUD операций, фильтрацией по нескольким полям и консольным интерфейсом

## Структура проекта
```

src/db/
├── backend/memory.py   # хранилище данных
├── main.py         # точка входа
└── tui.py              # интерфейс

```

## Запуск
```bash
python -m src.db
```

Предметная область

Студенты (id, first_name, second_name, age, gender)
